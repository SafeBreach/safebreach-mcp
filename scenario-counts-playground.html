get_scenario_simulation_counts

SafeBreach MCP · Studio server · read-only · SAF-35508
“How many simulations would this scenario produce, and which simulators produce them?”
One question, answered without running anything. It scores a scenario against the fleet as it stands right now and reports three numbers per step: the simulation count, and the counts contributed by each attacker and each target simulator.
Does not answer: “which attacks would run?”
It enumerates no attacks. Name an id to get_scenario_blocked_entities → answers ran with its count.
Does not answer: “why did nothing run?”
Constraints are never evaluated here. That is get_scenario_blocked_entities, and the hint routes there.
Does not answer: “what if every simulator were available?”
Counts are always runnable. The expected figure is not offered and cannot be derived from this response.
